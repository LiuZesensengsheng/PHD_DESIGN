## 目标

这里保存每一次会形成项目管理结论的会议纪要。会议可以是真人会议，也可以是一次明确的 AI 协作决策讨论。

每条会议纪要应该回答：

1. 这次讨论了什么。
2. 达成了什么结论。
3. 产生了哪些 TODO。
4. 哪些问题还没有决定。
