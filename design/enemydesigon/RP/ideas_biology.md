# 生物学

## 1. 豌豆

### 核心概念

- 孟德尔遗传
- 显性 / 隐性
- 分离定律

### 机制方向

#### 普通版本

- 战斗中固定存在 2 个亲代豌豆，二者组成一组杂交对。
- 每个豌豆各自带一组基因，例如 `A/a`。
- 显性基因决定当前可见性状，隐性基因暂时不表现。
- 杂交对每隔固定回合进行一次【结荚】。
- 结荚成功后，两个亲代豌豆退场，出生 2 个【子代豌豆】代替它们。
- 每个子代都从两个亲代处各继承 1 个基因，并根据组合表现本场唯一一对相对性状：
  - `A/A` 或 `A/a`：表现显性性状
  - `a/a`：表现隐性性状
- 每场只选择一组同维度的显性 / 隐性相对性状。
- 显性表达是稳定弱效果，隐性表达出现频率更低，但效果应明显更强。
- 备选性状组：
  - 高茎 / 矮茎：显性高茎获得少量格挡；隐性矮茎扎根更深，获得更多格挡或少量反击。
  - 圆粒 / 皱粒：显性圆粒回合结束回复少量 HP；隐性皱粒在低血时回复更多 HP。
  - 黄粒 / 绿粒：显性黄粒攻击略高；隐性绿粒攻击更高或附带 1 层负面状态。
  - 饱满荚 / 空荚：显性饱满荚结荚倒计时正常；隐性空荚结荚更快，但子代血量更低。
  - 光滑种皮 / 粗糙种皮：显性光滑种皮第一次受伤减伤；隐性粗糙种皮每次小额受伤后获得格挡。
- 玩家必须在同一回合内击杀两个亲代，才算真正打断本次杂交。
- 如果只击杀其中一个亲代，另一个亲代仍会完成杂交；机制表现可以是“备用花粉 / 自交补位”，继续生成下一代。
- 基础版本可以用固定子代序列表达孟德尔比例，例如 `A/A -> A/a -> A/a -> a/a`，前三个子代表现显性，第四个子代表现隐性。
- 场上豌豆数量默认保持为 2，压力来自代际性状变化，而不是无限铺场。

### 首版建议

- 首版使用固定子代序列，不使用真正随机遗传。
- 每场只使用一组显性 / 隐性相对性状。
- 结荚倒计时必须可见。
- 玩家需要在同一回合击杀两个亲代，才能真正打断本轮杂交。

### 调整边界

- 场上豌豆数量保持为 2，不做无限铺场。
- 子代继承 HP 比例或固定偏低 HP 二选一，定稿前不要两套混用。



**可加**

- 子代豌豆可以继承亲代剩余 HP 比例，避免替换机制变成免费回血。
- 也可以让新一代血量固定偏低，突出“幼苗”阶段的击杀窗口。

## 2. DNA 双螺旋

### 核心概念

- 碱基配对
- 互补链
- 一边变化，另一边响应

### 机制方向

#### 普通版本

- 成对出现：A 链 / T 链，或 C 链 / G 链。
- 玩家以其中一条链为目标时，另一条互补链获得对应收益。
- 示例：
  - 攻击 A 链：T 链获得格挡
  - 攻击 T 链：A 链下次攻击提高
  - 攻击 C 链：G 链回复少量 HP
  - 攻击 G 链：C 链获得力量
- 如果两条互补链在同一回合都受到伤害，则本回合配对被打断，不触发互补收益。

### 首版建议

- 每场只使用一组互补链规则，例如 A/T 或 C/G。
- 互补收益表必须固定且显示给玩家。
- 如果两条链同回合都受到伤害，则本回合不触发互补收益，这是核心 counterplay。

### 调整边界

- AOE 是舒适答案，但不应是唯一答案。
- 不要在同一场中切换多套碱基配对表。
