# 物理

## 1. 薛定谔的猫

**要点**

- 主角打出第一张**以猫为目标**的牌时，才公开本回合真实意图。
- 首版定稿为：**只认直接指向猫的牌才算观测**。
- 溅射、反击、间接伤害首版不算观测，避免玩家无意触发。

**可加**

- 长期不指向猫则意图更难读或蓄力重置。
- 与另一只怪共享一条隐藏规则，指向猫时一起公开。

**调试边界**

- 观测后本回合真实意图必须立刻显示。
- 如果之后想让“任意伤到猫都算观测”，应作为高阶版本单独测试。

## 2. 麦克斯韦妖

**要点**

- 一个怪物有**两个血条**，像两个腔。
- 妖按简单规则把玩家造成的伤害分到不同血条，例如高伤打一边、低伤打一边，或奇数费打一边、偶数费打一边。
- 只要其中一个血条被打空，之后所有伤害都能打到另一个血条。

plus: 两个血条，每回合取高血量

基础版本名字不一样，plus版升级为神兽

**可加**

- 每场只用一种分类规则，不要频繁切换。
- 与薛定谔同场时，未观测的伤害可以先由妖分类；观测猫后，本回合伤害全部打向玩家指定的一边。

**首版建议**

- 普通版只使用一种固定分类规则，例如高伤 / 低伤，或奇数费 / 偶数费。
- 分类规则必须显示在怪物说明或血条旁边。
- plus / 神兽版才使用“每回合取高血量”的额外收益。

**调试边界**

- 不要在普通版中每回合切换分类规则。
- 如果使用两个血条，必须明确击破其中一个血条后的结算方式。

## 3. 拉普拉斯妖

**要点**

- 方案 A：妖会做一个很粗的预言，只预测玩家下回合的一个简单行为，例如第一张牌是不是攻击牌、或总共会不会打出 3 张以上牌。
- 如果玩家真的按预言行动，妖获得格挡、强化或追加一次小伤害；如果玩家反着来，妖本回合少动一次或预言失效。
- 预言不要猜具体牌，只猜一个维度，避免机制太复杂。

普通版

猜下一回合玩家第一张牌类型/或者抽到的第一张牌

plus版本

- 方案 B：每回合玩家打出的第一张牌会被妖完美预判，并按牌类型反制一次。
- 攻击牌：结算后增加hp；防御牌：TBD；技能牌：+力量。

plus 版本定位：

- 标记为精英 / 后期版本，不作为普通怪首版。
- 反制表必须补全后才能实现。
- 反制强度要有上限，避免玩家每回合第一张牌都像被禁止。




废弃
- 方案 C：因果已定。妖给玩家挂「死兆」标记，伤害不立刻结算，而是在下回合开始或玩家打出第 N 张牌后爆发。（死灵法师既视感）

## 4. 芝诺的乌龟

**要点**

废弃
- 方案 A：乌龟开场有几层「距离」，例如 3 层。玩家每打出一张**以乌龟为目标**的牌，距离 -1。
- 距离没有归零前，乌龟受到的伤害降低；距离归零后，本回合后续伤害正常。
- 回合结束时，乌龟恢复 1 层距离，表现出“总是差一点追上”的感觉。





普通怪版本：

- 方案 B：乌龟血量越低，受到的伤害越低，代表越接近终点越难真正到达。
- 低血减伤只分 2-3 档即可，例如半血以下减伤、濒死时再提高，避免计算复杂。

首版建议：

- 普通版只使用 2-3 档低血减伤。
- 每档减伤需要在血条或状态上显示。
- 不要同时加入逐次受伤递减，否则普通版会过于拖战。


神兽乌龟：

当前回合，每受伤一次，下次受到伤害 -1

神兽定位：

- 标记为精英 / 后期版本。
- 强烈克制多段小伤害，因此不能作为普通早期怪。
- 每回合开始时递减记录清零，避免永久拖慢战斗。
