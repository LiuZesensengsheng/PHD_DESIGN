# 点名主题

## 主题概述

场景为助教在课前**点名**。总有爱迟到的学生，甚至有人帮他们**代到**。主角的目标是：在迟到学生赶到教室前，找到他们的名字并记缺勤。  
若迟到学生成功到达教室，主角会感到深深挫败（**超高压力伤害**）。

---

## 敌人配置

- 固定：1 [代到学生](../敌人设计/点名/代到学生.md) + 1 [拖延怪](../敌人设计/点名/拖延怪.md) + 1 [迟到学生](../敌人设计/点名/迟到学生.md)
- 迟到学生数量随主题强度提升  
- 迟到学生到达前会以「空桌子」形式出现，倒计时结束后未击退则变为 [代到学生](../敌人设计/点名/代到学生.md)，详见 [迟到学生](../敌人设计/点名/迟到学生.md#机制) 设计。
- 强度 2 / 3 默认采用**错峰倒计时**：多个「空桌子」不应全部在同一回合自然归零，除非遭遇脚本明确标记为高压变体。

---

## 本主题任务池

本主题的**完成条件**（专属 + 通用）见 → [任务列表 · 点名](../../任务系统/任务列表.md#点名)。

---

| 结果     | 效果 |
|:---------|:-----|
| 任务成功 | 场上**所有**迟到学生到达教室的倒计时 **+1 回合** |
| 任务失败 | 场上**所有**迟到学生到达教室的倒计时 **-1 回合** |

### 任务结算细则

- 点名主题任务默认**同时出现**，玩家可从当前任务中选择要优先完成的任务。
- 任务完成成本为**可选成本**：由任务条件本身决定玩家是否投入牌、能量或行动节奏，不额外强制支付固定资源。
- 若迟到学生基础倒计时为 3 回合，则每次任务成功 / 失败的改变量为 **1 回合**。
- 任务成功 / 失败影响场上**所有**仍处于「空桌子」阶段的迟到学生，而不是只影响最近到期或指定目标。
- 任务成功可以让倒计时超过初始值；这是“买时间”的主题奖励，不设初始值硬上限。
- 若倒计时因任务失败降至 0 或更低，按迟到学生到场规则结算；多名迟到学生同时到场时，应优先通过强度 2 / 3 的默认错峰避免不可读的连续爆发。

### 到场与转化细则

- 「空桌子」是普通敌人目标，可被攻击、被 AOE 命中、被施加状态并被击杀。
- 「空桌子」被击退后直接移除，不造成到场压力伤害，也不转化为代到学生。
- 「空桌子」每轮执行自己的行动：造成伤害并使倒计时 -1；若因此归零，立刻造成到场压力伤害并转化为代到学生。
- 任务失败使倒计时降到 0 或以下时，立刻造成到场压力伤害并转化。
- 转化会生成新的代到学生并继承原位置；不继承空桌子的负面状态、倒计时或临时效果。
- 固定代到学生一直存在；每个成功到场的空桌子会额外转化出一个代到学生。
- 多个空桌子同时归零时，每个各自造成一次到场压力伤害；强度 2 / 3 默认用错峰避免普通版本同时爆发。
- 代到学生只治疗仍处于「空桌子」阶段的迟到学生，不治疗已转化的代到学生。
- 【补交】是状态污染牌，进入抽牌堆，可正常抽到、弃掉、消耗、净化或按现有状态牌规则自然处理；它不是任务，也不是永久诅咒。
